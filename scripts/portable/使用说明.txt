争鸣 · AI 辩论场 — Windows 便携版

1. 将 ZIP 完整解压到一个固定文件夹，建议放在桌面或文档目录。
2. 双击「启动争鸣.cmd」，浏览器会自动打开。
3. 首次可以直接点「先看一场演示」。真实模型在「模型接入」中配置。
4. 使用结束后，可在网页中结束比赛，再双击「停止争鸣.cmd」。
5. 打不开时双击「环境诊断.cmd」，查看文件校验和服务状态。

便携版内置 Node.js 运行时，使用时无需安装 Node、Git 或下载 npm 依赖。
适用于 64 位 Windows 10 / 11。真实模型需要网络与自己的 API Key。
本机访问地址固定为 http://127.0.0.1:5173/。

数据与更新
模型配置默认保存在 %LOCALAPPDATA%\Zhengming。
勾选记住的密钥由当前 Windows 账户加密。更换电脑或账户需要重新填写。
比赛档案与战绩保存在浏览器中，重要对局请导出。
不同浏览器或访问地址的档案分别保存。
更新时先结束比赛、停止旧服务，再将新版 ZIP 解压到新文件夹并启动。
固定数据目录与相同的本机地址用于保留配置及浏览器档案。

从源码版迁移
若此前使用源码版，可在停止两个版本服务后，将源码目录 .local\providers.json
复制到 %LOCALAPPDATA%\Zhengming\providers.json。请先备份目标文件。
该文件只在自己的电脑中迁移，记住的密钥受原 Windows 账户保护。

日志与诊断
服务日志位于 %LOCALAPPDATA%\Zhengming，环境诊断会生成本地文本报告。
诊断报告只记录版本、校验和运行状态，不包含密钥或比赛正文。
文件缺失或校验失败时，请重新完整解压官方 ZIP。
