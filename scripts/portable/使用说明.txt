Zhengming · AI Debate Arena — Windows portable beta

1. Extract the complete ZIP into a stable folder.
2. Double-click 启动争鸣.cmd to start the app in your default browser.
3. Select EN in the top bar, then Watch a demo. Demos work without an API key.
4. Configure live providers, model IDs, and API keys under Model connections.
5. End the match before running 停止争鸣.cmd to stop the service.
6. Run 环境诊断.cmd to check package integrity and service status.

The package includes its Node.js runtime and application dependencies.
Supported systems are 64-bit Windows 10 and Windows 11.
Live model requests use your provider's API permissions and billing.
The local address is http://127.0.0.1:5173/.

Language
Use EN / 中文 in the top bar to select the interface language.
New matches use the language selected at launch.
Existing topics and speeches are displayed in their recorded language.

Data and updates
Provider configuration is stored in %LOCALAPPDATA%\Zhengming.
Remembered keys are encrypted for the current Windows account and machine.
On another account or device, enter the key again.
Archives and standings are stored in the current browser and app origin.
Export important matches before changing browsers or clearing browser data.
Finish the current match and stop the old service before updating.
Extract the new version into a new folder and launch it using the same browser.

Migrating from source
Stop both services, back up the destination configuration, then copy the source
.local\providers.json file into %LOCALAPPDATA%\Zhengming\providers.json.
Windows-encrypted keys require the original machine and account.

Diagnostics
Logs and local diagnostic reports are stored in %LOCALAPPDATA%\Zhengming.
Reports include version, integrity checks, and service status.
If files are missing or damaged, extract a fresh copy of the official ZIP.
