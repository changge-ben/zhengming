争鸣 · AI 辩论场 · 打开方法

1. 按键盘 Win + E，打开文件资源管理器。
2. 打开保存或解压后的争鸣项目文件夹。如果下载的是 ZIP 文件，需要先完整解压。
3. 双击「启动争鸣.cmd」。如果电脑隐藏了扩展名，它可能显示为「启动争鸣」，类型为「Windows 命令脚本」。
4. 等待几秒，浏览器会自动打开网站。

如果浏览器没有自动打开，在浏览器地址栏输入：
http://127.0.0.1:5173/

电脑重启后，需要重新双击启动脚本。服务运行后，可以关闭启动窗口。
仅打开网址不会自动启动服务；连接不上时，先双击启动脚本。
已经勾选「记住 API Key」的模型无需重新填密钥。

备用方法：在此文件夹的终端执行 npm run dev，保持终端运行，再打开上面的网址。
