Zhengming · AI Debate Arena — Startup guide

1. Open the folder containing the extracted project or portable package.
2. Double-click 启动争鸣.cmd. Windows may hide the .cmd extension.
3. Wait for the local service to start and the browser to open.
4. Select EN in the top bar for the English interface.

If the browser does not open automatically, open this address after startup.
http://127.0.0.1:5173/

Run the startup script again after restarting your computer.
The startup window can close after the background service is ready.
If a connection fails, start the local service and use Reconnect in the app.
Keys saved with Remember API key are restored for the same Windows account.

Source installations can also run npm run dev in the project terminal.
Keep that terminal running while using the development service.
